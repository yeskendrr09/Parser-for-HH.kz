# HH.kz Data Science Job Parser 🚀

A lightweight, custom Python web scraper built to automate the collection and analysis of Data Scientist job openings from HeadHunter (hh.kz).

## 📌 Features
- **Smart Anti-Bot Bypass:** Uses custom browser headers to avoid instant blocks and captchas.
- **Targeted Tech Stack Extraction:** Automatically scans job descriptions for core skills: **Python, SQL, and Tableau**.
- **Clean Data Export:** Aggregates findings and neatly formats them into a structured Excel (`.xlsx`) sheet.

## 🛠️ Tech Stack
- **Python 3.12**
- **Requests:** For handling HTTP network requests.
- **BeautifulSoup4:** For parsing HTML structures and navigating target elements.
- **Pandas & OpenPyXL:** For data manipulation and generating Excel reports.

## 🚀 How to Run It Local

### Install the required dependencies:
pip install requests beautifulsoup4 pandas openpyxl


#### Run the parser:
python perviyparser.py

##### Once the execution finishes, you will find a freshly generated hh_vacancies.xlsx file in your project directory. 🎉
